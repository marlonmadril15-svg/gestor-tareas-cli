# Gestor de Tareas CLI

Aplicacion de consola en Python para gestionar tareas: agregar, listar, completar y eliminar.

## Requisitos previos
- Python 3.8 o superior
- Git

## Instalacion
```
git clone https://github.com/USUARIO/gestor-tareas-cli.git
cd gestor-tareas-cli
```

## Uso
```
python app.py
```
Seleccione una opcion del menu escribiendo su numero y presionando Enter.
